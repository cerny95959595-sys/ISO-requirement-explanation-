# Instalace ISO Requirements & Audit Atlas 2026

## Doporučený postup – samostatný GitHub repozitář

Aplikaci nenahrávejte přes stávající Knowledge Atlas v repozitáři `game`. Vytvořte nový repozitář, například:

```text
iso-audit-atlas
```

1. Stáhněte ZIP `ISO_Requirements_Audit_Atlas_2026_GitHub_Pages.zip`.
2. Na PC jej rozbalte pomocí **Extrahovat vše**.
3. Otevřete rozbalenou složku. Soubor `index.html` musí být přímo uvnitř této složky.
4. V GitHubu vytvořte nový repozitář `iso-audit-atlas`.
5. Pro bezplatný GitHub Pages musí být repozitář veřejný.
6. V repozitáři otevřete **Code → Add file → Upload files**.
7. Nahrajte celý rozbalený obsah, nikoli samotný ZIP ani nadřazenou složku.
8. Potvrďte **Commit changes**.
9. Otevřete **Settings → Pages**.
10. Nastavte **Deploy from a branch → main → /(root)** a uložte.
11. Po dokončení nasazení bude adresa přibližně:

```text
https://cerny95959595-sys.github.io/iso-audit-atlas/
```

## iPhone

1. Otevřete zveřejněnou adresu v Safari.
2. Počkejte na úplné načtení.
3. Klepněte na **Sdílet**.
4. Vyberte **Přidat na plochu**.
5. Spouštějte aplikaci z nové ikony.

Po prvním úspěšném online načtení aplikace pracuje i offline.

## Windows / Mac

Otevřete adresu v podporovaném prohlížeči. V nabídce prohlížeče použijte **Install app / Instalovat aplikaci**, nebo aplikaci používejte přímo jako web.

## Sdílení s kolegy

Kolegům stačí poslat veřejnou webovou adresu. Každý uživatel má audity, poznámky a výsledky uložené pouze ve svém prohlížeči. Mezi zařízeními se automaticky nesynchronizují.

## Důvěrnost

GitHub Pages z veřejného repozitáře je veřejný. Vestavěná ISO databáze je určena k veřejnému vzdělávání, ale do repozitáře nevkládejte interní postupy, FMEA, zákaznické informace, reklamace, osobní údaje ani jiné důvěrné soubory. Odkazy zadané uvnitř aplikace se ukládají lokálně v prohlížeči, přesto je pro firemní produkční použití vhodnější SharePoint/Azure s Entra ID.

- ISO 9001:2015 + Amd 1:2024 je aktuální certifikační základ k datu sestavení; 6. vydání je očekáváno v roce 2026 a finální požadavky je nutné ověřit po publikaci.
- ISO 45001:2018 + Amd 1:2024 zůstává aktuální; nová revize je pouze ve fázi návrhu.
